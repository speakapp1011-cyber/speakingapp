# 英語フレーズ学習アプリ（MVP・ステップ①）

教材の画像から会話で使える英語フレーズをAI（Gemini）で抽出し、確認・編集して
保存できるアプリです。冷蔵庫管理アプリと同じ技術構成（素のHTML/JS＋Vercel
サーバーレス関数＋Gemini API＋ブラウザ内保存）を流用しています。

## 今回のステップでできること

- 教材画像のアップロード（カメラ撮影にも対応）
- Geminiによる重要フレーズの自動抽出（フレーズ／意味／例文／ニュアンス）
- 抽出結果の確認・編集・手動追加
- フレーズの保存（同じフレーズの重複登録を防止）
- 登録済みフレーズの一覧表示・削除

まだ実装していないもの（次のステップ）：今日の練習プロンプト生成、過去フレーズ
からの復習選択、復習プロンプト生成、daily_studies（学習記録）の保存。

## 構成

```
phrase-app/
  index.html              ← フロントエンド（このファイルだけで動く）
  api/extract-phrases.js  ← 画像からのフレーズ抽出（Gemini APIを中継）
  package.json
```

## セットアップ

### 1. Gemini APIキーを用意する

すでにお持ちのGemini APIキーをそのまま使えます（冷蔵庫アプリと共通のキーで
問題ありません）。お持ちでない場合は https://aistudio.google.com/apikey で
無料発行できます。

### 2. Vercelにデプロイする

1. この `phrase-app` フォルダをGitHubの**新しいリポジトリ**にアップロード
   （冷蔵庫アプリとは別のリポジトリ・別のVercelプロジェクトにしてください）
2. Vercelのダッシュボードで「Add New... → Project」からそのリポジトリを選択
3. 「Environment Variables」に以下を追加
   - `GEMINI_API_KEY` … Gemini APIキー
4. 「Deploy」を押すと、`https://（プロジェクト名）.vercel.app` が発行されます

### 3. iPhoneでホーム画面に追加する

発行されたURLをSafariで開き、共有ボタン→「ホーム画面に追加」で完了です。

## データの保存について

フレーズは、この端末のブラウザ内（localStorage）に保存されます。追加の
データベースや有料サービスは一切使っていません。別の端末・別のブラウザとは
データが共有されない点にご注意ください。

## API呼び出しについて

Gemini APIを呼び出すのは「画像からのフレーズ抽出」の1箇所だけです。確認・
編集・保存・重複チェックはすべてブラウザ側の処理で完結するため、無駄な
API呼び出しは発生しません。
